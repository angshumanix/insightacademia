# Build a lightweight study-pack catalogue framework

The current brochure lists unverified packs and routes enquiries through obsolete channels. This change introduces a static product catalogue framework with reusable templates, four learning categories and the confirmed InsightAcademia Telegram account. The default staging output lists no products as available. A separate, noindex design preview contains three clearly labelled demo packs and sample prices.

Includes responsive green/gold branding, optional catalogue filters, accessible navigation/FAQ behavior, order-process pages, policy drafts, metadata, sitemap, conditional product schema and publication-readiness checks. No paid files, checkout integration or runtime backend are included.

Validation: eight Python contract tests, JavaScript syntax and menu/filter behavior checks pass. Browser visual/end-to-end QA remains pending because the available browsers could not reach the local preview server. The offline review document supports page navigation and desktop/mobile frame sizes for inspection.
